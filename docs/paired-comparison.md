# 配對試驗差異

原規格F13及17.2要求有意義時顯示paired differences。原有比較會檢查Pair ID
人口及排列，但只有每個變體嘅分佈／候選排名，冇逐對差異。0.1.29補一條
唯讀流程：明確選擇驗收定義、參考變體及比較變體，差異＝比較減參考。
唔按名稱猜邊個係baseline，亦唔更改原有品質優先排名。

## 使用及數據規則

「任務結果與實驗」下方新增「逐對比較試驗差異」。資源選單包括Token、
未快取Input、觀察時段、完整已記錄工具區間聯集、失敗工具、重試候選、
壓縮標記，以及每個已保存價格貨幣。每頁20組，可查看所有已載入配對。

只使用每筆試驗匯入時嘅固定資源，唔用目前帳本或價目重算。按Pair ID聯集
保留兩個已選變體全部試驗；缺少Pair ID、缺少一邊或重複側成員都保留，
唔任揀一筆或將差異補零。失敗／排除但有量測嘅差額仍入描述分佈，並明示
未通過雙邊驗收。全部變體嘅原試驗表及總成本保持，冇將較便宜失敗試驗
當成勝出者。非paired protocol或截短人口唔計配對分佈。

Token及時間用bigint精確差額；美元等貨幣逐幣計算，只有兩邊完整定價先有
差額。不同價目快照及固定條件／Cache未知／未控制因素有提示。完整工具
時間未保留時只保留原快照小計，唔用小計計完整時間差。API等值差額唔係
訂閱退款或因果節省。中位數保留負數半值同13位小數貨幣中位數。

每行可以展開帳本及價目版本。共同比較算法版本係paired-difference/1。
原有比較嘅fixedConditions搬到共享純函式，冇更改既有勝出門檻。

## 報告及私隱

配對區內報告保留同一參考／比較設定；JSON及Markdown包含全部原試驗人口
同新配對資料，CSV係指定配對資源表。包含試驗ID、各自帳本revision、價目
snapshot IDs、計算版本、目前報告adapter／policy版本；CSV另列Requested／
Observed模型，未知保持空白。文字用既有redaction／Markdown／CSV escaping，
只有嚴格數字格式嘅資源欄位可以保留負號作數字。Project匯出限制照常生效。

沿用完整分頁預覽、五分鐘期限及保存完全相同內容。更改比較設定清除舊
預覽，較早回覆唔可覆蓋新選擇。私隱事件即時清除試驗／配對，epoch fence
拒絕之前讀取、保存後刷新及驗收後刷新嘅回覆，再讀取新資料；配對選擇重設。
冇新IPC方法、DB schema、Collector或任意程式執行能力。
