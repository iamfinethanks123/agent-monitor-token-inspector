# 原始檔案可用性

0.1.15喺數據品質加入明確按鈕檢查，將「保留統計」同「原始檔仍可喺原位核對」分開。檢查全工作區首200個保留來源，唔受日期／模型等用量篩選影響，亦唔需要等完整解析品質聚合完成。

只從Monitor自己資料庫取得來源路徑，renderer只提供有界來源ID清單。每個ID都限制目前workspace；非本機來源直接標為遠端未核對，唔連線或探測遠端原始路徑。本機只檢查目前啟用嘅來源目錄，逐層拒絕來源符號連結同非一般檔案，只量測檔案metadata及R_OK權限。目錄停用、目錄不可用、檔案缺少、無權限同未知狀態保持分開。唔讀原始bytes、唔新增授權、唔改游標、唔刪統計、唔重新解析。

介面顯示完成時間、分類計數及可展開逐來源結果。檔案存在唔代表內容完整／冇改過，亦唔代表帳戶全部歷史已收齊。結果係一次檢查嘅快照；按掣先更新。來源清單改變時清除舊結果，遲到回覆唔會發布到另一清單；失敗時保留同一清單嘅舊結果及舊時間。未保留來源同其他workspace ID唔會透露路徑。
