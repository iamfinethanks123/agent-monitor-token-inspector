## 已實作嘅主要功能

- 統一工作區：Agent Monitor 任務地圖、Trace、用量帳本、跨設備統計、Context／工具分析、建議及實驗共用導覽。圖表由分鐘至整日，沿用設備／Run／Agent／模型／Project／Provider／服務級別範圍。
- 美元主單位：按逐筆模型及可用價目換算 API 等值成本，保留未知模型／快取／路線／服務級別嘅限制；可切換 Token、模型價目或自訂價目。Input／Cache、Output／Reasoning 子項唔重複相加，數字唔當成訂閱帳單。
- 可追查帳本：response、interval、先前 aggregate、控制計數及被隔離衝突保持分開；總數與逐筆用量可固定版本、追查全部支持記錄／來源量測。
- 調查：持久 metadata Timeline、搜尋／篩選、工具結果配對、模型歸屬轉換、Compaction、Retry／Polling、跨 Agent 共同操作及獨立覆核標記。
- 品質與報告：解析缺口、未支援格式、來源進度、結構指紋、Monitor 自身資源；JSON／Markdown 診斷匯出，完整帳本／分析／實驗報告及 CSV 表。先固定預覽，再保存完全相同嘅內容。
- Collector：新增設備及匯出配對設定、加密用量 metadata 同步、撤銷、斷線 spool、離線批次匯入及刪除傳播。原始 Codex 檔案只讀。
- 有界建議方案：按候選類型列出一個改動、驗收／比較及回退條件；意圖／抑制候選先核對。可預覽、複製／保存 metadata 方案，同樣受 Project 匯出政策保護；唔自動執行。
- Outcome／Benchmark：任務目標、驗收條件、固定試驗快照、失敗／取消／排除人口及品質優先比較。第一版受控執行採用已確認嘅本機離線測試／驗收指令，需具體設定預覽及明確啟動。

## 需要條件或同意嘅能力

- 三設備統計已接入。Windows 設備經用戶授權SSH代啟動、DPAPI配對及正式Collector同步已確認，保留手動重啟；完整歷史、全部平台／長斷線驗收另行核對，見collector-windows.md。
- 內容指紋依賴 Monitor 自己嘅安全儲存金鑰。不可用時保留證據不足，唔改用明文金鑰或重設系統鑰匙圈。
- Context manifest 只限經同意嘅 owned client；現有 Desktop 對話維持被動量測。被動 Context 估算唔等於完整模型輸入。
- Account quota 顯示兼容記錄中可取得嘅被動快照。0.1.13總覽可按鈕讀取官方帳戶累計，與可追溯帳本分開；即時額度／餘額／重設等其他帳戶功能未啟用。未知訂閱額度唔會換成虛構Token allowances，見account-usage.md。
- 本機 Benchmark 尚未執行用戶嘅真實專案指令。既有隔離 fixture 通過唔等於實際任務驗收。

## 保持關閉／尚未提供嘅模式

外部 AI 解釋、AI 任務自動執行同原始對話／工具內容同步維持關閉。本機刪敏片段保留／搜尋已有明確逐Project同意，預設關閉並有截斷及容量／保留期界線，見local-content-search.md。完整平台／安全／效能驗收及指定規格其他 gate 仍需按 `spec-status.md` 核對。
