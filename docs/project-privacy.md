# 逐 Project 私隱設定

設定頁管理本機 Monitor／中央 Hub 所持有嘅資料。Project 使用工作區專屬識別；
未識別群組可能包含多個項目，可限制保留期、匯出及預覽，但不可當成單一
已知 Project 作整體刪除。

可以設定事件 Metadata 日數、用量／帳本日數，留空沿用整體政策。保留期按
Monitor 接收時間；用量保留期不得短於事件期。縮短政策而有現有記錄超期時，
原生確認框會先列出影響數量。完整原始檔案副本仍關閉；已識別Project可明確
啟用最多30日嘅有界刪敏文字片段及本機搜尋，預設0日。日數不超過事件期；
縮短整體期而衝突時須先降低該Project文字期。詳見local-content-search.md。

統計匯出限制喺 JSON、Markdown、CSV 產生及最終保存時執行。混合來源包含
禁止匯出嘅 Project 時，會拒絕匯出而要求調整範圍／政策，唔會暗中輸出部分
之後聲稱係完整總數。保存視窗開住期間改政策或刪除，舊預覽會失效，檔案
唔會寫出。明確政策操作同最後保存串行執行，並重新驗證政策版本。

原始 Trace／證據預覽由後端限制。無法安全分開混合 Session 原始內容時，
整份原始預覽會被封鎖。原版節點活動、路徑、角色／暱稱及 Run 標題亦按
來源權限遮蔽。保存設定會關閉已開啟原始預覽；檔案讀取後會再核對政策。

刪除 Project 前列出觀察／用量／來源數及混合來源數。刪除只按每筆觀察嘅
Project 歸屬處理，保留其他 Project 觀察。相關共享 Trial、Incident、Budget
history、Context Manifest 衍生副本亦會清理。同一 Project ID 後續匯入被排除。
Schema 1 Manifest 冇獨立 Project 身份，包含已刪 Project 嘅混合 Thread 後續
Manifest 匯入會被拒絕。原始 logs、Client 本機索引、備份及已匯出檔案不被刪。

Schema 10 保存政策、Project／來源關係、保留位置及已移除用量位置。重新
解析須核對原始位元內容，保留已驗證身份；缺少金鑰唔會將已知身份改成未知，
另一把金鑰造成身份改變則保留上次結果。受限制來源嘅新記錄失去 Project 身份
會標示 PROJECT_IDENTITY_UNAVAILABLE，唔會用未知身份繞過限制。明確設定嘅
未識別群組仍然可以繼續收集統計，跟隨該群組政策。

原始檔重讀或收到同一來源／位置重播，保留標記與排除會阻止資料返入索引。
累積 counter 跨過移除觀察時，嗰段範圍會隔離；之後完整範圍可恢復計算。
已識別、屬於其他 Project 嘅回應會保留，唔會將已刪歷史再當 remainder 計入。

29 個相關測試通過，涵蓋混合 Source 保留／刪除、counter 缺口、重播、身份
穩定、舊報告失效、原始檔未改、Manifest 抑制、未識別群組統計及 Schema 9→10
帳本備份／外鍵檢查。隔離原生介面驗證包括政策按鈕、Trace／報告封鎖、保存
視窗期間改權限而檔案不寫出，以及恢復權限後重新開啟子 Agent Trace。

本次安裝唔會替真實 Project 啟用文字保留或刪資料。Client中央constraints／
套用receipt已提供，保留較嚴格本機選擇，見project-policy-sync.md。中央metadata-only模式唔讀遠端原始內容。本機正數刪敏片段保留／
搜尋已提供，唔等同完整原始檔案副本。
