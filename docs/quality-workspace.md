# 數據品質工作區

0.1.20將原本同時堆疊嘅內容分成四個入口：資料覆蓋（原始檔檢查、解析／缺口、信任界線、診斷報告）、設備健康（Client快照）、額度記錄（被動視窗及最近200筆）、Monitor資源（CPU、RSS、Heap、DB及WAL）。所有原有功能保留，冇將長表放入預設畫面。

預設資料覆蓋；四個入口用既有石墨／淺藍、Avenir及相同導覽節奏。較窄視窗改兩列，按鈕有目前選擇、原生鍵盤及可見焦點。切換後只掛載目前面板，額度及解析重查唔會喺其他入口繼續由通知觸發；既有cleanup／scope／privacy fence保持。全域篩選原樣傳入解析／額度；原始檔檢查、設備健康同Monitor資源仍清楚標示各自全域範圍。

scripts/smoke-quality-workspace.mjs驗證四個入口、原有面板、未選中時冇額度／解析查詢、鍵盤選取、日期scope傳遞同12-token帳本保持，並產出隔離資料寬／窄截圖。原有quota/device-loading/source-availability流程跟新入口更新。完整所有寬度／screen-reader及所有平台驗收仍按原spec gate，唔由代表畫面推斷。

0.1.20已安裝；實際原生可讀樹確認四個入口、資料覆蓋內容及Collector健康表。健康表顯示Ubuntu及Windows各自收到時間，唔假定兩台一直在線。介面工具曾只改按鈕狀態而內容未切換，鍵盤後可讀樹有健康表，但截圖仍停留舊內容，座標操作另回報noWindowsAvailable；因此未將真實額度／資源頁切換當成已完成驗收。隔離Electron流程四頁均通過。啟動後內容指紋仍顯示逾時，受保護密文未改，唔當作鎖匙圈已修復。
