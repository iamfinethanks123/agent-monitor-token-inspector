# 設備載入與健康資訊

0.1.18修正初次載入時將未知設備清單顯示成「未有配對設備」嘅問題。Collector健康卡分開顯示讀取中、更新失敗及已確認空清單；失敗時保留上次收到嘅設備，唔將未知當成零／未配對。

總覽／品質及設備頁會立即讀取既有輕量device-activity資料，唔需要先有完整用量快照。新初始化嘅設備小計保持null、帳本版本保持未知；之後收到完整快照先填入。已有小計更新健康資料時仍沿用舊用量版本，唔會將心跳當成新增用量。

總覽完整devices回覆一到便發布，唔等其他統計Promise全部成功。設備頁完整用量讀取亦合併為一個進行中加一個待更新，避免來源變動通知令多個重查堆積。輕量心跳／健康更新保留原有合併及60秒更新；未新增逐秒輪詢、Token推算或重新配對。

tests/inspectorDeviceActivity.test.ts驗證輕量初始化冇捏造用量／版本，並保留已知小計。scripts/smoke-device-loading.mjs用隔離Electron真實renderer，將其他統計設為失敗、完整設備用量暫停回覆；確認讀取中唔顯示未配對，輕量資料仍顯示設備／未知小計，之後更新失敗保留舊資料，只有成功空清單先顯示未配對。真實已安裝App結果見STATE.md；唔由fixture推斷完整網絡可靠性或所有平台驗收。
