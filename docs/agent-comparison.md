# 跨 Agent 工作比較

「分析與建議」加入同一範圍嘅 Agent 選擇、來源親子／Fork 關係、用途、
自己嘅帳本用量、共同輸出同並排工具歷史。點擊工具時間會同步兩邊游標；
共同操作可切換顯示位置，完整已保留歷史用 Timeline 開啟。原始工具文字
仍然只經現有本機證據入口及 Project 私隱權限讀取，唔會複製入比較結果。

先用同一設備、已識別共同 ancestry、operation 同輸出指紋分桶，再比較所選
兩個 Agent；唔做全 Agent 兩兩比較。至少 256 bytes 已捕捉輸出先形成候選。
部分輸出捕捉仍然標為不完整；目標字串指紋一致唔代表同一個已解析檔案或
Worktree revision。任務分工／環境狀態未記錄時保留限制，唔會推定浪費。

同一設備／Thread／Call ID 嘅來源鏡像合併；不同 Thread 共用 Call ID 嘅
內容排除為可能複製歷史。真實不同 Call ID 嘅執行仍然顯示。跨設備 execution
origin 未有證據，現有 Collector 又只傳統計，所以唔建立跨設備重複工作結論。

用途可以標為實作、覆核、獨立測試、研究、平行探索或共同起始資料。
來源角色嘅推定同用戶標記分開顯示。共同內容有已記錄／明確標記嘅驗證用途
時保留「覆核／獨立驗證」分類；使用者亦可以對一對 Agent 嘅某組內容標記
刻意／必要重複。呢啲標記唔會改動 Token 帳本，亦唔會自動扣效率分。

關聯用量只使用目前範圍內、支援證據落喺已配對工具開始／結果範圍嘅 selected
response 成員。控制 counter、aggregate、interval 同被隔離記錄唔會分配到工具。
鏡像證據使用 ledger_links 對返同一 canonical response。一組內及多組聯集各自
去重；每組數字唔應相加。可避免用量仍然未知，需要保持品質嘅對照實驗。

source time overlap 先合併兩個 Agent 各自嘅時間區間，再算交集，唔會相加
平行時長。來源時間缺失或逆序時保留未知。通訊 metadata 只提供本機證據
指標；唔推定收件方已收到／看過，冇紀錄亦唔代表資訊不可用。

顯示最多 50 組共同內容、每邊 50 項相鄰工具紀錄；一組關聯用量最多連結
每邊 10 個工具範圍。超過上限會標示，全部 Agent 已選擇用量仍然獨立保留。
沒有工作分數、可避免 Token 或虛構節省金額。

用途及刻意覆核標記保存在本機。來源刪除／metadata 到期清理相關標記同依賴，
避免保留已刪除來源嘅比較副本。Schema 11／wire-v2 保持不變，沒有更改 Collector
傳送內容、帳戶憑證、私隱授權或原始 Codex log。

JSON／Markdown 分析報告包含預設所選比較對象、共同操作、聯集用量同限制；CSV 可以選「跨 Agent 共同操作」。報告仍使用現有凍結預覽、Project 匯出權限同秘密文字遮罩；唔包含內容指紋或原始交接訊息。
